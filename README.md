# AniLauncher

Лаунчер Minecraft для себя и друзей: сборки Vanilla, Fabric и Quilt, вход через Microsoft, автоматическая Java, новости и арты из официальной ленты Mojang, темы и профиль с рамками.

## Что умеет (версия 1.3)

**Сборки**
- Сколько угодно сборок: Vanilla, Fabric, Quilt, Forge, NeoForge. Название, арт (официальный Mojang или своя картинка), версия игры и загрузчика, память, аргументы Java.
- Игра, библиотеки, ресурсы и нужная Java скачиваются сами. Forge и NeoForge ставятся через их официальные установщики (первый раз — пара минут).
- Импорт сборок: Modrinth (`.mrpack`) и Prism/MultiMC (`.zip`). Экспорт в `.mrpack`.
- Миры и бэкапы: бэкап мира в один клик, восстановление (текущий мир сначала сохраняется отдельно), удаление.
- Счётчик наигранного времени, быстрые папки модов/миров/ресурспаков/шейдеров/скриншотов.
- Запуск Bedrock, если он установлен из Microsoft Store.

**Фон главной** — по умолчанию официальные арты Minecraft. Можно поставить свою зацикленную гифку или видео (а также картинку), слайдшоу своих скриншотов или живой пиксельный пейзаж, где день и ночь идут по реальному времени: рассвет, закат, звёзды, луна, падающие звёзды, птицы. Погода — дождь, снег, светлячки — меняется сама или выбирается вручную, со звуками дождя и ветра.

**Виджеты главной** — время игры за неделю, последние скриншоты, свежие релиз и снапшот Minecraft, календарь игры за полгода. Каждый виджет можно скрыть.

**Проверка модов перед запуском** — лаунчер заранее находит недостающие зависимости, неподходящие версии, несовместимые и задвоенные моды, моды для другого загрузчика или версии игры. Читает данные самих модов (работает и без интернета) и данные Modrinth. Проблемный мод можно отключить прямо из окна проверки.

**Точки восстановления сборки** — перед обновлением модов, оптимизацией и сменой версии лаунчер сам сохраняет моды и настройки; откат в один клик. Можно создавать точки и вручную.

**Звуковые наборы** — классика, 8-бит, мягкие, деревянные, кристальные; у каждой темы свой набор, громкость регулируется.

**Каталог модпаков** — модпаки Modrinth с фильтром по версии и загрузчику: одна кнопка, и готовая сборка с артом модпака.

**Консоль игры** — живой лог с фильтром, режим «только ошибки», копирование. Если игра вылетела, лаунчер объясняет причину: каких модов не хватает, мало памяти, не та Java, конфликт модов, проблема видеодрайвера — и открывает отчёт о вылете.

**Запуск сборки** — размер окна или полный экран, автоподключение к серверу, своя Java, дублирование и закрепление сборок. Лаунчер может сворачиваться или прятаться, пока идёт игра.

**Моды и ресурсы (Modrinth)**
- Поиск модов, ресурспаков и шейдеров с фильтром по версии и загрузчику, сортировка, выбор версии.
- Установка с зависимостями, включение/выключение, удаление.
- Проверка обновлений и «Обновить всё», а также автообновление перед запуском (в настройках).
- «Оптимизировать» — Sodium, Lithium, FerriteCore, ImmediatelyFast, Entity Culling, ModernFix, Dynamic FPS (для Forge/NeoForge — свои аналоги) под версию сборки.
- Включить/выключить все, страница мода на Modrinth в один клик.

**Скины**
- 3D-просмотр с анимацией, коллекция скинов, скин с аккаунта.
- Надеть скин на аккаунт, выбрать плащ.
- NameMC прямо в лаунчере: нажимаешь «Download» на странице скина — он попадает в коллекцию.
- Профессиональный редактор: рисование прямо по 3D-модели и по текстуре, кисть 1–4 px, ластик, линия, прямоугольник, заливка (по части или всей текстуре), замена цвета, тени и блики, «шум» для фактуры, пипетка (Alt+клик), зеркальное рисование левой/правой стороны, основной и второй цвет, палитра и HEX, слои «основа/одежда», скрытие частей тела, позы (ходьба, бег, полёт…), перевод рук классика ↔ тонкие, импорт/экспорт PNG, 150 шагов отмены и горячие клавиши (B, E, L, U, G, R, D, N, I, X, M, [ ], Ctrl+Z/Y/S).

**Скриншоты** — общая галерея из всех сборок: просмотр, копировать в буфер, сохранить копию, удалить.

**Профиль и вид**
- Вход через Microsoft, создание и смена ника; офлайн-профили после входа с лицензией.
- Профиль лаунчера: ник, аватарка, 10 рамок, включая анимированные (радуга, огонь, вода, эндер).
- 6 готовых тем и редактор своих: цвета, скругление, обводка, свечение, отдельные элементы (кнопка «Играть», меню, карточки, заголовки). Темы можно экспортировать и отправлять друзьям (`.anitheme`).
- Русский и английский, звуки и анимации (отключаются), свой шрифт заголовков.
- Подсказка по памяти: лаунчер видит, сколько её в компьютере.
- Лента новостей и обновлений Minecraft.

**Новое в 1.3**
- **Быстрый старт** на главной: продолжить последний мир или зайти на последний сервер одной кнопкой (миры — с Minecraft 1.20+, серверы — во всех версиях).
- **Сезонные события**: снег, гирлянда и еловая ветка на Новый год; тыквы, паук, листья и летучие мыши на Хэллоуин; торт со свечами-цифрами, шарики и конфетти в день рождения. Дата рождения указывается в настройках («Праздники»), там же можно посмотреть каждое оформление.
- **Профили управления**: сохранить раскладку клавиш и применить её к любой сборке.
- **Режим «Ютубер»**: кнопка в заголовке окна скрывает ник, аккаунт, IP серверов и показывает свою подпись на главной.
- **Карточка игрока**: картинка со скином, часами в игре, любимой сборкой и активностью за 16 недель — копировать или сохранить PNG.
- **«Как у друга»**: вставляешь ссылки Modrinth/CurseForge, коллекцию Modrinth, видео YouTube (моды из описания) или просто список названий — лаунчер находит моды и ставит в выбранную сборку.
- **Перетаскивание файлов** в окно: мод, ресурспак, шейдер, мир (.zip) или модпак — лаунчер сам поймёт, что это, и предложит сборку.
- **Глубокие настройки** (вкладки и поиск):
  - вид: акцентный цвет поверх любой темы, скругление, масштаб интерфейса, шрифт, стеклянные панели;
  - главная: высота и затемнение картинки, порядок и скрытие блоков, сколько сборок показывать, своя надпись на кнопке «Играть»;
  - интерфейс: компактное меню из значков, скрытие разделов, стартовая страница («где закончил»), место и время уведомлений;
  - события: каждый праздник включается отдельно, количество частиц, украшения, частицы только на главной;
  - звуки: отдельно наведение и нажатия;
  - игра: консоль при запуске, аргументы Java для всех сборок;
  - данные: сохранить настройки в файл, загрузить, сбросить вид.
- **Базовые моды**: свой набор для каждого загрузчика (например, Mod Menu для Fabric), ставится в каждую новую сборку автоматически.

**AniLauncher Link** — свой маленький мод, который лаунчер подключает к сборкам на Fabric, Quilt, Forge и NeoForge, Minecraft от 1.20 до 26.3:
- лежит в папке лаунчера, а не в `mods`; на Fabric и Quilt скрыт в списке Mod Menu (как библиотека), на Forge и NeoForge виден в списке модов;
- уведомления лаунчера прямо в игре: обновления модов, найденные несовместимости, любые сообщения;
- «Пульт игры» (кнопка рядом с «Игра запущена» или в меню сборки): поле зрения, дальность, яркость, размер интерфейса, FPS, громкость — меняются сразу; ресурспаки включаются и выключаются без выхода; профили управления применяются на ходу;
- ресурспак, скачанный во вкладке «Моды», сразу включается в запущенной игре;
- скриншоты сразу появляются в галерее с названием мира, измерением и координатами;
- время в каждом мире (видно в окне «Миры»), в профиле — где ты сейчас играешь;
- выключается в «Настройки → Игра → AniLauncher Link». Исходники мода — в папке `companion`: Fabric/Quilt — `./gradlew buildAll` (нужна Java 25), Forge/NeoForge — `companion/forge`, `./gradlew buildAll` (нужны Java 17 и 21): два универсальных файла — для версий со старыми именами (Forge 1.20–1.20.4, NeoForge 1.20.2–1.20.4) и для всех более новых.

**Надёжнее установка Forge и NeoForge**: исправлен запуск NeoForge (игра не загружается дважды); если файлы установщика пропали или он сломался, лаунчер переустанавливает Forge сам и при неудаче пробует другую Java.

**Резервная копия лаунчера** («Настройки → Аккаунт и данные»): всё в одном zip — настройки, темы, профиль, скины, профили управления, статистика и все сборки с модами; по желанию миры и скриншоты, точки восстановления, аккаунты. Minecraft, Java и библиотеки не копируются — скачаются заново. «Восстановить из копии» возвращает всё после переустановки Windows.

**Отчёт об ошибке одной кнопкой** (консоль сборки, меню сборки, настройки): логи игры и запуска, отчёты о вылетах, список модов, лог установщика Forge/NeoForge, сведения о компьютере и твоё описание. Токены входа, имя пользователя Windows и Client ID вычищаются.

**Трей** (значок у часов): левый клик открывает лаунчер; в меню — последние сборки, «Остановить игру», «Консоль», «Пульт игры», режим «Ютубер», «Выйти»; пока идёт игра, на значке зелёная точка. В «Настройки → Интерфейс → Окно и трей»: крестик сворачивает в трей, запуск вместе с Windows, уведомления Windows о вылете, когда лаунчер свёрнут. Повторный запуск лаунчера открывает уже работающее окно.

**Статус в Discord** («Настройки → Аккаунт и данные → Discord»): «Сборка: …», загрузчик и версия, в меню / в одиночном мире / на сервере (через AniLauncher Link), таймер игры; статус в лаунчере, когда игра не запущена. ID приложения Discord встроен; в GitHub можно задать свой через переменную `DISCORD_APP_ID`. В режиме «Ютубер» название сборки скрыто, адреса серверов и названия миров не показываются никогда.

**Автообновление лаунчера**: при запуске лаунчер проверяет, вышла ли новая версия, и предлагает «Обновить и перезапустить» (сборки, миры и настройки остаются). Вручную — «Настройки → Аккаунт и данные → Обновления лаунчера». Обновления подписаны: лаунчер ставит только то, что подписано ключом проекта.

### Как выпустить новую версию

Один раз: положи ключ подписи в Secrets репозитория (`TAURI_SIGNING_PRIVATE_KEY` и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`, см. файл с ключом). Репозиторий должен быть **публичным** — иначе лаунчеры не смогут скачать обновление со страницы выпусков.

Каждый раз:
1. Залей изменения через GitHub Desktop (Commit → Push).
2. GitHub → **Actions** → **Build AniLauncher** → **Run workflow**.
3. В поле «Выпустить версию» впиши номер больше текущего (например `1.4.0`), в «Что нового» — коротко про изменения. **Run workflow**.
4. Через 10–15 минут на странице **Releases** появится выпуск, а лаунчеры предложат обновиться.
5. В GitHub Desktop нажми **Fetch/Pull** — GitHub сам записал новый номер версии в файлы.

Если поле версии оставить пустым — соберётся обычный установщик (вкладка Artifacts), без выпуска и без обновления у других.

**Пока нет:** сервер для профилей друзей и подключения к их мирам (следующий большой этап), импорт сборок CurseForge (их загрузки требуют ключ API CurseForge).

## Как получить установщик

1. Залей проект в свой репозиторий на GitHub (через GitHub Desktop).
2. Открой вкладку **Actions** → **Build AniLauncher** → **Run workflow**.
3. Через 10–15 минут внизу страницы запуска появится архив **AniLauncher-windows** с файлом установки `.exe`.

Windows может показать «Неизвестный издатель» — это нормально для программ без платной подписи: «Подробнее» → «Выполнить в любом случае».

## Вход через Microsoft: Client ID

Каждому лаунчеру нужен свой «паспорт» в Microsoft — Client ID. Он не секретный, его можно хранить открыто.

1. Зайди на https://portal.azure.com своим аккаунтом Microsoft.
2. Найди **App registrations** → **New registration**.
3. Название: `AniLauncher`. Тип аккаунтов: **Personal Microsoft accounts only**. Redirect URI не нужен. Нажми **Register**.
4. Слева **Authentication** → внизу **Allow public client flows** → **Yes** → **Save**. Без этого вход по коду не заработает.
5. На странице **Overview** скопируй **Application (client) ID**.

Дальше два варианта:
- **Встроить в лаунчер** (удобно для друзей): в репозитории **Settings → Secrets and variables → Actions → Variables → New repository variable**, имя `MS_CLIENT_ID`, значение — твой Client ID. Пересобери лаунчер.
- **Или** вставить Client ID в самом лаунчере: «Настройки и темы» → «Вход».

### Одобрение Mojang

Новые приложения Mojang пускает к API Minecraft только после проверки. Пока её нет, вход остановится на последнем шаге с сообщением, что приложение ещё не одобрено.

Заявка: https://aka.ms/mce-reviewappid — там нужны Client ID и Tenant ID (оба на странице **Overview**), название приложения и почта. Рассмотрение занимает время, и одобрение не гарантировано. После одобрения изменения вступают в силу в течение суток.

## Разработка

```
npm install
npm run tauri dev      # запуск в режиме разработки
npm run tauri build    # сборка установщика
```

Нужны Node.js 20+, Rust и (на Windows) WebView2 — он уже есть в Windows 10/11.

Файлы лаунчера хранятся в `%APPDATA%\dev.anidius.anilauncher`: сборки, библиотеки, ресурсы, Java и настройки.
