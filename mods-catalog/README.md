# Мои моды в лаунчере

Положи сюда `.jar` своих модов — по одному файлу на каждую версию Minecraft — и отправь (Commit → Push).
GitHub сам соберёт `catalog.json`, и через пару минут моды появятся в лаунчере во вкладке «Моды → Найти».

- Имя файла должно содержать версию игры: `mod-1.0.1+mc1.21.11.jar`.
- Название, описание, автор и иконка берутся из самого мода.
- Своё описание (например, по-русски): файл `descriptions.json` вида `{"interactionpreview": "Текст…"}`.
- Новая версия мода: просто положи новый jar рядом — лаунчер предложит обновиться.
